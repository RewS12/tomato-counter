# Риски и критика

| Риск | Вероятность | Что делаем |
|---|---|---|
| **Нет/плохой интернет на площадке** (сервер!) | неизвестна | хот-спот с телефона → ноутбук; всё локально, интернет не нужен |
| Брандмауэр / cleartext HTTP блокирует запросы | высокая | network security config в APK, открыть порт в Windows — проверить в первые 2 часа |
| IP ноутбука меняется | высокая | поле IP в настройках APK, не хардкод |
| Живая камера на сцене даёт плохой результат | высокая | основное демо на фото из галереи; живой кадр — кульминация; принести томаты |
| Датасет теплицы ≠ наши фото (domain shift) | средняя | доразметить свои фото, честно показать ошибки |
| Зрелость ломается от света | высокая | обучать 2 класса + аугментации яркости; разбор ошибок |
| Утечка теста в обучение | средняя | 3 скрытых фото отложить сразу |
| Нет проектора / нельзя зеркалить телефон | неизвестна | scrcpy на ноутбук или результаты дублируются в веб-UI |
| «А вы обучали?» | 100% | [[Вопросы жюри]] |

## Критика (актуальная)
1. Сценарий ТЗ — загрузка фото → галерея обязательна, камера — плюс.
2. Мобилка промышленного качества не требуется → не полировать UI, вкладываться в модель и честную оценку.
3. Сервер = зависимость от сети → хот-спот обязателен, протестировать заранее.
4. Для питча сильнее история «куст по датам», чем «одно фото».
