# Датасеты

## ✅ Используем: Laboro Tomato
- Источник: https://github.com/laboroai/LaboroTomato · архив `laboro_tomato.zip` (1.6 ГБ, без регистрации)
- 804 фото теплицы (643 train / 161 test), 3024×4032, COCO JSON с масками и боксами
- 6 классов: `b_/l_` (обычные / черри) × `fully_ripened / half_ripened / green`
  - fully_ripened ≥ 90% красного, half_ripened 30–89%, green < 30%
- Сведение к 2 классам ([[ADR-001 Выбор культуры]]): fully_ripened → **ripe**; half_ripened + green → **unripe**
- После конвертации: train 1330 ripe / 6451 unripe, val 341 / 1655 — **дисбаланс ~1:5**
- Лицензия **CC BY-NC-SA 4.0** — некоммерческая, указать в питче.

### Подводные камни (уже решены)
- 235 фото повёрнуты через EXIF (orientation=6), а разметка — по повёрнутому кадру → в `ml/prepare_dataset.py` делаем `exif_transpose` перед конвертацией. Без этого терялось 38% данных.
- Размечены только томаты **переднего плана**; дальние на фоне без боксов → модель приучена их игнорировать. На демо снимать близко.
