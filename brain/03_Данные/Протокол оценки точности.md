# Протокол оценки точности

## Метрики
- **Ошибка подсчёта:** |N_модель − N_вручную| на фото, MAE по выборке.
- **Precision / Recall** (бонус ТЗ): матчинг боксов по IoU ≥ 0.5.
- **Точность категории** на сопоставленных боксах (confusion matrix 2×2).

## Типы ошибок (для слайда «честный разбор»)
- Пропуск (перекрыт листом / мелкий / в тени)
- Ложное срабатывание (листья, блики, похожие объекты)
- Двойной бокс на один плод (NMS)
- Неверная категория (освещение, полузрелый)

## Скрипт — `ml/eval.py` ✅
Тот же детектор, что и сервер для APK ([[Архитектура]]). Матчинг жадный, IoU ≥ 0.5, без учёта класса; зрелость считается отдельно на сопоставленных.

```bash
# боксы (YOLO txt) → P/R + картинки ошибок
python ml/eval.py --images data/hidden_test --labels data/labels/hidden_test
# только количества глазами (CSV file,ripe,unripe) — быстро для 3 скрытых фото
python ml/eval.py --images data/hidden_test --counts data/labels/hidden_counts.csv
```
Выход: `runs/eval/<имя>/report.md` → готовая таблица для слайда «модель vs вручную»; `errors/*.jpg` → слайд «честный разбор ошибок».

## Результаты
### val Laboro (161 фото) — tomato_v1
| conf | Насчитано (вручную 1996) | MAE | P | R |
|---|---|---|---|---|
| 0.25 | 2422 | 3.12 | 0.76 | 0.93 |
| 0.5 | 2015 | 1.86 | 0.87 | 0.88 |

- Зрелость на найденных: **96.6%** верно.
- FP завышены: модель находит томаты заднего плана, которых нет в разметке Laboro.
- Найдено: дубли (маленький бокс внутри большого на одном плоде) → можно добавить подавление вложенных боксов.
