# Модель детекции

## Кандидаты
| Вариант | Плюсы | Минусы |
|---|---|---|
| YOLO (Ultralytics, v8/11), дообучить на датасете культуры | Быстро обучается (n/s за 1–2 ч на GPU), экспорт в TFLite/NCNN/ONNX | Лицензия AGPL-3.0 (для хакатона ок, упомянуть) |
| Готовая модель с Roboflow Universe | Ноль обучения | Неизвестное качество, зависимость от API/интернета |
| Zero-shot (Grounding DINO / OWL-ViT / YOLO-World) «tomato» | Без датасета | Медленно, плохо на мобиле, хуже на перекрытиях |

**Рекомендация:** YOLO-n/s, дообученная на открытом датасете выбранной культуры. Zero-shot — как быстрый бейзлайн в первые часы, чтобы UI было на чём собирать.

## Параметры для фиксации
- Размер входа: 640 (компромисс скорость/мелкие плоды)
- conf threshold: подобрать по [[Протокол оценки точности]]
- NMS IoU: важно для перекрывающихся плодов — тестировать 0.45–0.6

- Базовые веса: **YOLO11s** (COCO), дообучение на Laboro Tomato (2 класса), 60 эпох, imgsz 640, batch 16, RTX 4060 8 ГБ.

- Скрипты: `ml/prepare_dataset.py` → `data/tomato_yolo/`; `ml/train.py` → `models/tomato_v1.pt`.

- Время: 60 эпох за 13 мин.
- **Метрики на val Laboro** (161 фото): P 0.876 · R 0.829 · mAP50 **0.905** · mAP50-95 0.766 (ripe mAP50 0.885, unripe 0.925).

### Проверка на чужих фото (Wikimedia, 3 шт.)
- Куст: оба красных найдены (заглушка нашла 1 из 2), **зелёный, обрезанный краем кадра, пропущен**; один бокс смещён.
- Студийное фото 4 томатов на белом: найдено 3 из 4, задний пропущен, боксы неплотные.
- Вывод: **domain shift** (теплица Laboro → другие условия). Лечение: доразметить 30–50 своих фото и дообучить (v2); на демо снимать с близкого расстояния, как в Laboro.

## Обучение v2 — негативы (2026-10-17) ✅ по умолчанию
- **Баг из поля:** сфотографировали яблоки → v1 насчитала «томаты» с уверенностью 0.9+. Причина: в обучении были только томаты, модель не видела «круглый плод, который НЕ томат».
- **Фикс:** 400 фото яблок/апельсинов/мячей из COCO с пустой разметкой (`ml/fetch_negatives.py`), фото с томатами в подписях исключены.
- Ложные «томаты» на 63 фото без томатов: **687 → 8** (conf 0.25); на 5 яблоках с Wikimedia: 36 → 0.
- На томатах не хуже: P/R 0.782/0.920 (было 0.763/0.926), зрелость 96.7%.
- Цена: на необычном макроснимке пропустила крупный томат, перечёркнутый стеблем.
- **Для питча:** хороший пример «нашли ошибку → поняли причину → исправили и измерили».
