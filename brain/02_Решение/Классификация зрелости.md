# Классификация зрелости (2 категории)

## Подход 1 — классы прямо в детекторе
Детектор сразу выдаёт `ripe` / `unripe`. Нужен датасет с такой разметкой (напр. Laboro Tomato — у него есть стадии зрелости, можно схлопнуть в 2).
- ➕ одна модель, учитывает контекст
- ➖ зависит от того, как размечен датасет

## Подход 2 — детектор «плод» + правило по цвету
Детектор ищет просто «плод», затем внутри бокса считаем долю «красных» пикселей в HSV (или LAB) → порог.
- ➕ объяснимо жюри, легко крутить порог вживую
- ➖ **освещение** (ТЗ прямо об этом говорит) → нужна нормализация (серый мир / CLAHE) и порог по hue, а не по RGB

## Рекомендация
Делать **1**, а **2** — как объяснимый запасной вариант и для слайда «как мы боролись с освещением». Можно показать их согласие/расхождение.
