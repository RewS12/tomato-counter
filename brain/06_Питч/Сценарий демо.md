# Сценарий демо

1. Открыть APK → выбрать 1–2 подготовленных фото из галереи → рамки + сводка.
2. Показать таблицу «модель vs ручная разметка».
3. **Кульминация:** снять принесённые томаты на столе вживую → результат.
4. План Б: если APK/сеть упали — тот же сценарий в запасном веб-UI на ноутбуке; план В — заранее записанное видео демо.

## Чек-лист перед выходом
- [ ] Телефон заряжен, авиарежим/хот-спот настроен
- [ ] Фото в галерее офлайн
- [ ] Томаты на месте (красные + зелёные)
- [ ] Зеркалирование экрана телефона на проектор проверено
- [ ] Видео-запись демо на ноутбуке
