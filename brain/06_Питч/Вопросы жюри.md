# Ожидаемые вопросы жюри

- **Вы обучали модель сами?** → Базовые веса: ____; дообучили на ____ (N фото, M эпох); пороги подобраны на ____.
- **Как с перекрытиями?** → NMS-порог, примеры ошибок, честно: скрытые за листьями не ищем (по ТЗ не требуется).
- **Как с освещением?** → нормализация цвета / аугментации; примеры, где ломается.
- **Чем лучше, чем считать руками?** → скорость, повторяемость, история по датам.
- **Работает без интернета?** → да в пределах локальной сети: телефон и ноутбук на одном хот-споте, внешний интернет не нужен. On-device — следующий шаг.
- **Какая точность?** → цифры из [[Протокол оценки точности]].
