# ADR-003 Камера vs загрузка фото

## Контекст
ТЗ описывает сценарий загрузки фото и проверку на заранее подготовленных + 3 скрытых снимках. Идея команды — APK с камерой.

## Решение
Поддерживаем **оба** входа: галерея (обязательный путь для MVP и оценки) + камера (вау-фактор). Live-видео с рамками — только бонус.

## Последствия
Демо строим на галерее, живой кадр — кульминация. См. [[Сценарий демо]].
