# ADR-002 Где выполняется модель — ✅ Сервер

## Решение
Модель на **сервере** (ноутбук с GPU, FastAPI). APK на Kotlin — тонкий клиент: снимок/галерея → `POST /detect` → рисует рамки по JSON.

## Почему
- В команде есть опыт Kotlin, но не TFLite → on-device съел бы время.
- Есть GPU → быстрый инференс и дообучение на одной машине.
- Модель можно менять до последней минуты без пересборки APK.

## Последствия / что сделать
- **Сеть на площадке неизвестна** → телефон раздаёт хот-спот, ноутбук подключается к нему; APK ходит на IP ноутбука. Адрес сервера — настраиваемое поле в приложении, не хардкод.
- Android: разрешить cleartext HTTP (`usesCleartextTraffic` / network security config) для локального IP.
- Брандмауэр Windows: открыть порт сервера.
- Ресайз фото на телефоне до ~1280 px перед отправкой (скорость).
- On-device — не делаем (возможно, упомянуть как «дальнейшее развитие»).
