# ml/

```bash
python ml/fetch_negatives.py   # 400 фото НЕ-томатов из COCO (яблоки, апельсины, мячи) → data/raw/negatives/coco
python ml/prepare_dataset.py   # Laboro + негативы → data/tomato_yolo (2 класса: ripe/unripe)
python ml/train.py --name tomato_v2   # YOLO11s, 60 эпох → models/tomato_v2.pt
python ml/eval.py --images data/hidden_test --labels data/labels/hidden_test   # оценка
```

## Оценка (`eval.py`)
Тот же детектор, что у сервера. Разметка:
- **YOLO txt** (`<имя_фото>.txt`, класс 0 = ripe, 1 = unripe; координаты по фото после EXIF-поворота) → precision/recall, матрица зрелости, картинки ошибок;
- **CSV количеств** (`--counts`, колонки `file,ripe,unripe`) → только ошибка подсчёта. Годится для 3 скрытых фото, посчитанных глазами.

Результат: `runs/eval/<имя>/report.md` (таблица для слайда), `results.csv`, `errors/*.jpg`
(зелёный = верно, оранжевый = не тот класс, красный = ложное срабатывание, синий = пропуск).
Флаги: `--conf`, `--model`, `--iou` (порог засчитывания, 0.5), `--limit`, `--name`.

Данные: Laboro Tomato (`http://assets.laboro.ai.s3.amazonaws.com/laborotomato/laboro_tomato.zip`,
1.6 ГБ, распаковать в `data/raw/laboro/`). Лицензия CC BY-NC-SA 4.0.

Зрелость на найденных (conf 0.25): верно 96.6%.
Большинство «ложных срабатываний» — реальные томаты на заднем плане, которые Laboro не размечал, поэтому precision занижена.
Реальная ошибка — дубль: маленький бокс внутри большого на одном плоде.
**Порог conf подбирать на своих фото**, не на Laboro.

## tomato_v2 (2026-10-17) — с негативами ✅ по умолчанию
**Проблема v1:** обучалась только на томатах → любой круглый плод считала томатом
(на фото с яблоками — 30 «томатов» с уверенностью 0.9+).

**Решение:** 400 негативных фото из COCO (`ml/fetch_negatives.py`): 280 яблок, 100 апельсинов, 20 мячей,
объект ≥ 1% кадра, фото с «tomato» в подписях COCO исключены (753 шт.). В датасет — с пустой разметкой,
337 train / 63 val. Свои снимки не-томатов класть в `data/raw/negatives/own/`.

| | v1 | v2 |
|---|---|---|
| Ложных «томатов» на 63 фото без томатов, conf 0.25 | **687** | **8** |
| то же, conf 0.5 | 384 | 2 |
| Яблоки с Wikimedia (5 фото) | 36 «томатов» | 0 |
| Томаты val Laboro: P / R (conf 0.25) | 0.763 / 0.926 | 0.782 / 0.920 |
| Томаты val Laboro: насчитано при 1996 (conf 0.5) | 2015 | 1978 |
| Зрелость на найденных | 96.6% | 96.7% |

**Цена:** v2 осторожнее на необычных кадрах: на макроснимке куста пропустила крупный томат,
перечёркнутый стеблем; половинку разрезанного томата не считает.
Лечится своими фото томатов (и яблок) в обучении.
