# AgroVision — архив для запуска на сервере

> **В этом проекте:** лендинг `https://agro.setly.space/` публичный; приложение `/app`, API `/apiv2/*`, загруженные фото `/media/*` и документация API защищены Basic Auth. Health `/apiv2/health` тоже закрыт авторизацией. Android API проекта — `/android-api/*` (проксируется на `server/`, порт 8002). Контейнер сайта слушает порт **8003**; Traefik на `147.45.141.224` проксирует трафик через WireGuard на `192.168.2.5`. Caddy из `docker-compose.public.yml` не используется. Логин/пароль — в `web/.env`.

Быстрый старт: `docs/РАЗВЕРТЫВАНИЕ_НА_СЕРВЕРЕ.md` или `Документы/03_Развертывание_и_ИИ.docx`.

**В архиве:** frontend, backend FastAPI, CV OpenCV, SQLite, собственные SVG/PNG-иконки, фотографии, 13 синтетических тестовых изображений, презентация, Dockerfile, Docker Compose, Caddyfile, требования, тесты, документация.

**Без CDN и внешних API в процессе работы.** Интерфейс использует системные шрифты, не загружает шрифты извне. Никаких библиотек иконок по внешним ссылкам. Для установки Python/Docker-пакетов Интернет потребуется.

**Запуск:**
1. `cp .env.server.example .env` (на Windows скопируйте вручную), поменяйте пароль на уникальный длинный.
2. `docker compose up -d --build`
3. На сервере: `http://127.0.0.1:8003` (порт задаётся `AGROVISION_PORT` в `.env`). С другого компьютера через SSH-туннель `ssh -L 8003:127.0.0.1:8003 user@server`.
4. Публичный домен через HTTPS: `docker compose -f docker-compose.yml -f docker-compose.public.yml up -d --build` (заполните AGROVISION_DOMAIN, DNS, порты 80/443).

**По умолчанию используется OpenCV HSV**; готовой YOLO-модели внутри нет. Для YOLO необходимы собственные совместимые веса, дополнительный пакет и проверка прав на использование. Подробнее `docs/КАК_ПОДКЛЮЧИТЬ_ИИ.md`.

**Безопасность:** базовый пароль — минимальная защита только для демо/ограниченного доступа; TLS обязателен для доступа из Интернета. Нет ролей, аудита, ограничения скорости, полноценных пользовательских аккаунтов. Не использовать как публичный многопользовательский продакшен без доработки.

**Данные:** Docker volume `agrovision_data` хранит SQLite и фото. Создайте регулярные резервные копии. `docker compose down` не удаляет volume, `docker compose down -v` удалит данные.

**Локальный режим без Docker** (не выставлять порт наружу): `python -m pip install -r requirements.txt`, `python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000`.

**Тесты:** `python -m pip install -r requirements-dev.txt && python -m pytest -q backend/tests` и `python -m backend.evaluate` (синтетическая выборка, не реальная точность).
