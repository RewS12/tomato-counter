# Фактический статус функций AgroVision (16.10.2026)

| Функция | Статус | Способ реализации | Границы |
| --- | --- | --- | --- |
| Загрузка пользовательской фотографии | Работает | Multipart POST + проверка формата, размера и декодирования | До 8 МБ; JPG/PNG/WebP; сервер необходим |
| Детекция отдельных плодов | Работает с ограничениями | OpenCV: HSV, морфология, контуры, фильтры формы | Зелёные плоды на фоне листьев, перекрытия и блики могут давать ошибки |
| Классификация цвета | Работает с ограничениями | Отдельные красная и зелёная маски HSV, ручная смена категории | Не является доказательством биологической зрелости или пищевой безопасности |
| Неопределённая категория | Реализована при ручной правке | Список объектов и серверная ревизия рамок | Автоматический алгоритм сейчас создаёт красную/зелёную категорию; отдельный класс неопределённости не обучен |
| Рамки / счётчики / экспорт изображения | Работает | Серверная разметка JPEG, объектный список, счётчики | Один контур может соответствовать нескольким соприкасающимся плодам |
| Ручное исправление результатов | Работает | Добавление/удаление рамок, смена категории, PUT с валидацией | Рамки задаются координатами; не графическое перетаскивание |
| Сохранение и повторное открытие | Работает | SQLite + UUID-файлы на локальном диске | Однопользовательское демо; нет авторизации или резервного копирования |
| Карточки растений | Работает | CRUD по API, SQLite | Нет многопользовательских прав доступа |
| Дневник / история / графики | Работает | CRUD наблюдений, история по сохранённым снимкам | Динамика зависит от сравнимости ракурсов; не подтверждённый прирост урожая |
| Листья и стебель | Демонстрационный | Цветовые индикаторы всей фотографии + ручные наблюдения | Листья отдельно не сегментируются; диагноз не формируется |
| Почва | Демонстрационный | Яркость/контраст кадра + ручной чек-лист | Не измеряются влажность корней, NPK, pH или истощение |
| Рекомендации | Частично автоматизировано | Шаблоны проверок и изменяемый вручную журнал задач | Без валидированного агрономического экспертного движка |
| Продажи | Работает локально | CRUD товарных лотов; черновик по фото; ручное подтверждение | Нет публикации на маркетплейс, оплаты и подтверждённого товарного остатка |
| База знаний | Работает | 8 локальных справочных карточек, серверный поиск и фильтры | Общие рекомендации, не индивидуальный агроплан |
| Оценка качества | Работает на синтетике | 3 отложенных иллюстрации, ground truth, one-to-one matching по IoU >=0,5 | Реальная агровыборка отсутствует; 100% precision не относится к теплицам |
| Мобильная вёрстка | Работает в проверенном сценарии | Адаптивный HTML/CSS/JS, нижняя навигация | Проверено через Chromium-шлюз на 375 px, но не на физическом телефоне |
| Камера | Частично | Стандартный file input браузера с подсказкой capture | Работа физической камеры на разных устройствах не проверена |
| PWA | Частично | Manifest + service worker для кэширования оболочки | Офлайн-CV, офлайн-запись и фоновая синхронизация отсутствуют |
| YOLO и диагностика заболеваний | Отсутствуют | Не подключены, запланированы на roadmap | Нельзя указывать как выполненные |

- `python -m pytest -q backend/tests` — **7 passed** (16.10.2026).
- `python -m backend.evaluate` — 3 синтетических контрольных изображения, GT=31, predicted=30, TP=30, FP=0, FN=1, precision=1,0, recall≈0,9677, MAE≈0,333.
- Локальный HTTP smoke-test: файл, отличный от примеров, POST `/apiv2/analyze/fruits` → 2 bbox (красный/зелёный); анализ и карточка растения доступны после перезапуска API.
- Прямая проверка URL из Chromium ограничена административной политикой тестовой среды; ранее браузерный сценарий проверялся с прокси к локальному FastAPI. Полный пользовательский e2e на целевой ОС должен быть проведён после скачивания.
