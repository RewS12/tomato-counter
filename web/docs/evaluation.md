# Проверка и интерпретация метрик

## Данные

10 основных **синтетических иллюстраций** в `data/demo`, 3 отложенные **синтетические иллюстрации** в `data/validation`, исходная разметка `data/annotations/ground_truth.json` создана одновременно с программной генерацией сцен. Это не натуральные фотографии и не независимая экспертная разметка реального хозяйства. Пороги OpenCV не подбирались по трём контрольным изображениям.

## Правило сопоставления

One-to-one greedy matching по максимальному IoU при пороге 0,5. TP — найденный объект с совпадением GT; FP — предсказание без пары; FN — GT без пары. Category accuracy — совпадение категории на matched pairs. MAE — среднее |predicted count − GT count| на 3 фото. Никакие значения случайно не генерируются. Время — длительность OpenCV-детекции, не полный request round-trip.

Запуск `python -m backend.evaluate`. Скрипт пишет `data/evaluation.json`, UI читает `/apiv2/evaluation`.

**По текущему тесту:** 3 изображения, 31 эталонный плод, 30 обнаружений, TP=30, FP=0, FN=1. Precision=1,0; recall≈0,9677; MAE≈0,333; accuracy категории на 30 сопоставленных объектах=1,0. Эти показатели **только для простых рисунков**. На реальных фото степень ошибки **не измерена**. Не цитировать данные как промышленный результат.
