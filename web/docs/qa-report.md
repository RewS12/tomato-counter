# Отчёт проверки 16.10.2026

## Выполнено

- **pytest/FastAPI TestClient:** 7 тестов, успешны: GET лендинг/app/health/data, загрузка PNG с новым содержимым, реальные bbox, пустой кадр с нулём объектов, изменения боксов через API, CRUD растений/наблюдений/лотов/рекомендаций, запрет удаления растения с наблюдениями, plant/soil без диагноза, проверка JPG MIME и неверного файла, отдельный holdout.
- **Динамика содержимого:** два разных изображения приводят к разным числам обнаружений. Результаты не подставляются по имени файла.
- **Chromium (ограниченная среда):** реальная JS-страница запущена с подменой сетевого транспорта тестовым шлюзом к работающему FastAPI; проверены маршрут обзора, переход в анализ, выбор тестового файла, POST анализа, появление результата, открытие модального окна и добавление растения. Прогоны 1360 и 375 px; обнаруженное переполнение 375 px исправлено; ошибка JS в этих сценариях отсутствовала. Прямой переход Chromium на localhost был заблокирован политикой тестовой среды, поэтому это **не end-to-end тест по настоящему URL браузера**.
- **Рендер лендинга:** статический HTML и CSS визуально проверены на 1440 и 375 px (без горизонтального переполнения).
- **Синтетическая проверка:** 3 holdout фото, GT=31, Pred=30, TP=30, FP=0, FN=1, Precision=1, Recall≈0.9677, MAE≈0.333.

## Границы проверки

Не проведены: кроссбраузерное тестирование Safari/Firefox; камера на физическом телефоне; реальная агровыборка; долгосрочный нагрузочный тест; полный аудит доступности, безопасности и приватности; реальная офлайн-синхронизация. Показатели бизнес-эффекта не измерялись. Работа программного PWA-кэширования проверялась только по составу файлов, не как офлайн-CV.
