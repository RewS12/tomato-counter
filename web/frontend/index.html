ОТВЕЧАЕМ НА ВОПРОСЫ

Важно знать
до первого анализа.

Как работает подсчёт?

По умолчанию алгоритм OpenCV выделяет цветовые области, ищет контуры и фильтрует их по форме. Отдельно можно подключить специализированную обученную YOLO-модель. Оба метода требуют проверки на реальных фото.

Какие культуры поддерживаются?

Для первой версии настроены только томаты. Другие культуры требуют отдельной подготовки и проверки.

Можно ли пользоваться со смартфона?

Да, интерфейс адаптивный. Браузер может предложить выбрать фото или открыть камеру.

Насколько точен анализ?

Метрики получены на трёх синтетических изображениях; они не гарантируют точность на реальных теплицах.

Требуется ли интернет?

После локального запуска Python-сервера интернет не требуется. Сервер нужен для CV и хранения данных.

Где хранятся фотографии?

На компьютере, где запущен демо-сервер, в каталоге runtime/images. В демо нет регистрации пользователей и защиты для публичного размещения.

Может ли сервис заменить агронома?

Нет. Фото не подтверждает пищевую безопасность, болезни, состав почвы и пригодность к продаже.
