AGROVISION / АГРОВЗГЛЯД — ГОТОВЫЙ КОМПЛЕКТ

1. БЫСТРЫЙ ПРОСМОТР БЕЗ УСТАНОВКИ
Откройте AgroVision_АВТОНОМНЫЙ.html двойным щелчком в Chrome/Edge.
Анализ выполняется локальным JavaScript/Canvas. SQLite/Python не нужны.

2. ПОЛНАЯ СЕРВЕРНАЯ ВЕРСИЯ
Установите Python 3.10+; в Windows запустите start.bat, macOS/Linux: sh start.sh.
Откройте http://127.0.0.1:8000 (приложение: http://127.0.0.1:8000/app).
Для первичной установки Python-зависимостей потребуется интернет.

3. КАК ПОЛЬЗОВАТЬСЯ
Анализ фото → выберите синтетический пример или собственное фото → Запустить анализ →
проверьте рамки → Сохранить в дневник → (опционально) Создать черновик лота.

4. ДОКУМЕНТЫ
Документы/01_Описание_кейса_AgroVision.docx — задача, метод, риски и итоги.
Документы/02_Инструкция_запуска_и_подключения.docx — запуск, подключение компонентов и FAQ.
presentation/AgroVision_16_slides.pptx — редактируемая презентация, 16 слайдов.
presentation/AgroVision_16_slides.pdf — версия для просмотра.

ВАЖНО: алгоритм OpenCV/HSV, не YOLO. Проверка качества проведена на 3 синтетических изображениях.
Данные не подтверждают пищевую безопасность или фактическую зрелость.
